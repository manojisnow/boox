## Packaged application and models

Fresh Compose project `boox160fresh` used isolated new volumes, application port 18096 and Ollama port 12437, all bound to localhost. The actual one-time `granite4:3b` pull completed, Ollama became healthy and the application started. Only the candidate image and host ports were overridden; the fresh acceptance suite used the Compose Ollama service.

A separate candidate on port 18097 migrated a read-only SQLite backup copy of an existing database. The original database was not modified. This candidate used native local Ollama 0.40.6 through Docker's host bridge for faster inference, with the same Granite weights. The synthetic browser/demo candidate on port 18098 used a separate fresh named database and that native model server.

Tested Granite digest: `89962fcc75239ac434cdebceb6b7e0669397f92eaef9c487774b718bc36a3e5f` (3.4B, Q4_K_M). Native inference used Apple M2 Metal; fresh Compose inference used container CPU. No cloud model was substituted.

`scripts/verify-release-package.py` passed all four checks on both fresh and migrated candidates: ordinary chat, CSV sum of 21, retained-file explanation and natural-language web research with source URLs. An initial fresh run was interrupted by the restart test due to test orchestration; a complete rerun after restart passed. Raw responses remain outside Git in private temporary storage.

`scripts/verify-local-memory.py --model granite4:3b --allow-preferences-update` passed all five checks on the disposable migrated copy: saved preferences and stale-version rejection, saved-note recall and context metadata, source-chat reset preserving an independent note, standalone-chat isolation, and an Agent CSV task with preferences enabled.

## Browser acceptance

Using only a fictional Weekend studio project, the packaged UI saved preferences, project instructions and a pinned decision. A streamed fresh-chat reply recalled the three saved features, and Context used listed the actual preferences/project note. CSV research returned 5 + 7 + 9 = 21; expandable activity showed attached-file reading. Reload restored the conversation, project and retained file. Research cancellation reached its persisted Cancelled state and restored controls. Browser error logs were empty at inspection.

Responsive checks at 375px and 320px found document scroll width equal to viewport width; the normal viewport was restored. This is not physical-device testing or formal accessibility certification. The earlier [UI regression record](ux-validation.md) covers broader interaction paths.
